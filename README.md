# Trabalho de Sistemas Distribuídos - Programação com Threads em Java

Este repositório contém a resolução das questões da atividade prática da disciplina de Sistemas Distribuídos, abordando conceitos fundamentais de concorrência, criação de threads e gerenciamento de estados em Java.

---

## Como Compilar e Executar os Códigos

Necessário ter o JDK (Java Development Kit) 8 ou superior instalado no ambiente.

### Exemplo de execução:
```bash
cd questoes/questao01
javac MinhaThread.java
java MinhaThread
```
